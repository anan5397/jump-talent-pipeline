Talent Pipeline · HR Admin

Internal tool -- add or close job openings directly on the live Google Sheet. Not linked from the public careers page.

Enter admin passphrase

Set once in the Apps Script project under Project Settings > Script Properties (key: ADMIN_KEY). Ask whoever deployed this if you don't have it.

Add a new opening

Saved directly to the Jobs tab -- shows up on the careers page and gets picked up by the matching agent automatically.

All openings

Every job on the sheet, including closed ones. Toggling status here updates the same Jobs tab.
